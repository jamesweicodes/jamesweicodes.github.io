# Venture Studio

`/venture-studio/` is the starting point for the next web application in the portfolio.

## Purpose

This route acts as a product operating shell while the exact app domain is still being defined. It gives the project a deployable home, reusable data model, and starter UX for:

- Product brief intake
- Readiness scoring
- MVP build modules
- Launch milestone tracking

## Files

- `src/app/venture-studio/page.tsx` - interactive route UI
- `src/lib/venture-studio.ts` - starter content, types, and scoring helper
- `src/lib/site-data.ts` - portfolio project card entry

## Next build passes

1. Replace the starter brief with the selected product domain.
2. Add persistence for saved briefs and launch milestones.
3. Connect AI-assisted prompts once the workflow is finalized.
4. Promote the highest-value module into the primary app experience.
